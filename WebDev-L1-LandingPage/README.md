# Task 1 - Landing Page

## Oasis Infobyte Internship

**Track:** Web Development & Designing  
**Level:** Level 1  
**Task:** Task 1 - Landing Page

## Objective

Build a visually polished static landing page for a product, service, or brand using HTML5 and CSS3.

## Project

**WebNova - Digital Web Solutions**

WebNova is a sample digital-service brand landing page created as an internship project. The page focuses on a clean layout, responsive design and a consistent visual style.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Responsive Media Queries

## Features

- Sticky navigation bar
- Navigation links
- Hero section
- Headline and subheadline
- Call-to-action buttons
- Features section
- About/project section
- Contact call-to-action section
- Footer with GitHub and contact links
- Responsive design for desktop, tablet and mobile
- Consistent colour palette
- Clean typography and spacing

## How to Run Locally

1. Download or clone the repository.
2. Open the `Task1_LandingPage` folder.
3. Double-click `index.html`, or open it with VS Code and use a Live Server extension.
4. The landing page will open in your browser.
